# JobHunting

el propósito de este proyecto es aprender a usar una IA para buscar empleos.

quiero explorar la forma de usar una IA para buscar empleos. para automatizar en plataformas como linkedin, glassdoor, etc.

creo que es algo que permite ahorrar tiempo y esfuerzo en la búsqueda de empleos.

se debe alinear con el mercado laboral y las necesidades de las empresas.

debe buscar ofertas de trabajo en las empresas que estén buscando talento.

el principal objetivo es que postule a ofertas de trabajo remotos, luego trabajos presenciales en area de desarrollo web y software. y por ultimo trabajo en el sector minero
