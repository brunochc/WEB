# Professional Portfolio - Bruno Henríquez Cano

## Overview
This repository contains the source code for my professional portfolio website. The project is designed to showcase my unique "Dual Profile" as both an **Engineer in Machinery & Electronic Systems** and a **Full-Stack Developer**.

The website serves as a bridge between my technical background in industrial optimization and my software development skills, demonstrating my ability to solve complex problems in both physical and digital environments.

## Key Features
- **Dual Profile Narrative:** A dedicated "About" section that integrates formal engineering experience with practical "life skills" (mechanics, construction).
- **Project Showcase:** A responsive grid layout displaying key projects with tech stack details and links.
- **Modern Aesthetic:** A custom dark theme design (`#0a192f`) with professional green accents (`#64ffda`), inspired by modern software portfolios.
- **Responsive Design:** Fully optimized for mobile and desktop devices using Bootstrap 5 and custom CSS media queries.
- **Contact Integration:** Easy access to contact methods including email and phone placeholder for future Canadian networking.

## Tech Stack
- **Frontend Framework:** React 19
- **Build Tool:** Vite
- **Styling:** CSS3, Bootstrap 5, Bootstrap Icons
- **Routing:** React Router DOM
- **Deployment:** (Planned) GitHub Pages / Vercel

## Getting Started

### Prerequisites
- Node.js (v18 or higher)
- npm

### Installation
1. Clone the repository:
   ```bash
   git clone https://github.com/brunochc/WEB.git
   ```
2. Navigate to the web directory:
   ```bash
   cd WEB/proyectos/ProfessionalWeb/web
   ```
3. Install dependencies:
   ```bash
   npm install
   ```

### Running Locally
Start the development server:
```bash
npm run dev
```
The application will be available at `http://localhost:5173`.
